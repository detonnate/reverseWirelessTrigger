# Head-Unit Enclosure STL

Place the final 3D-printable `.stl` files for the front/head-unit enclosure here.

Suggested eventual files:
- `head_unit_enclosure_base.stl`
- `head_unit_enclosure_lid.stl`

The final model should be dimensioned from the actual ESP32-C3, relay module, USB-C converter/cable routing and preferred mounting method before printing.
